Selecciona un CSV en UTF-8 con encabezados. Máximo 5 MB y 5000 registros.

Obligatorios: fullName y email (máx. 150 caracteres cada uno). El correo debe ser válido y único; se guarda en minúsculas.

Opcionales: password (máx. 72 bytes en UTF-8) y status. Si dejas la contraseña vacía, el backend genera una aleatoria; el usuario podrá establecerla mediante recuperación de contraseña.

Se asigna por defecto el rol bloqueado Cobrador. Si tienes el permiso roles:update, puedes elegir un rol alternativo para todas las filas de esta importación. Estados: ACTIVE (49, por defecto), INACTIVE (50), LOCKED (52) o SUSPENDED (53).

} @else if (resource === 'payments') {

Obligatorios: importKey (clave única del pago, máx. 150 caracteres), amount (0.01 a 9999999999.99, hasta 2 decimales), paidAt (AAAA-MM-DD) y method: CASH (81), TRANSFER (82) o CARD (83).

Identifica al cliente existente con al menos uno de estos campos: clientName (máx. 150), clientEmail (máx. 150) o clientPhone (máx. 30). Si hay varias coincidencias, agrega más datos hasta identificar un solo cliente.

Opcionales: collectorName y collectorEmail (máx. 150 cada uno, deben identificar un único cobrador activo), reference (máx. 255) y comment (máx. 500). Los pagos importados siempre se registran como completados.

Conserva la misma importKey al reintentar un pago: el backend rechaza claves ya importadas para evitar duplicados. No uses una clave nueva para el mismo pago.
